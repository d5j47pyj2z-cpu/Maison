# 🏠 Gestion Factures Maison

Application web/PWA pour suivre les factures et le budget du foyer.

## Mise en ligne avec GitHub Pages
1. Crée un nouveau dépôt GitHub.
2. Envoie les fichiers `index.html`, `manifest.json` et `sw.js`.
3. Dans **Settings → Pages**, choisis **Deploy from a branch**, puis `main` et `/root`.
4. Ouvre l'adresse GitHub Pages fournie.

## Fonctions
- Factures et catégories
- Montant et échéance
- Payée / à payer
- Recherche et filtres
- Budget mensuel
- Revenus du foyer
- Graphique par catégorie
- Import/export JSON
- Fonctionnement hors connexion après première visite
